# DLCF AFIT Saintly Intellectuals Hub

Digital platform for Deeper Life Campus Fellowship (DLCF), Air Force Institute of Technology (AFIT), Kaduna.

## Features

- Authentication and role-based access for students, student executives, associate coordinators, and system administrators.
- Profile management with academic details, fellowship units, avatar, and campus residence.
- Academic course registration, course-slip uploads, semester GPA records, and Academic Director result verification.
- Peer mentorship pairing for students and academic mentors.
- Past-question repository with level targeting and downloads.
- Scholarship management with deadlines and application links.
- Study-plan generation and spiritual nurture resources.
- Confidential counseling tickets with coordinator replies, status tracking, and email notifications.
- Fellowship forum with unit notices, pinning, likes, and threaded comments.
- Fellowship media repository for flyers, audio, video, and YouTube sermon links.
- Student Executive and Associate Coordinator directories with contact actions.
- Real notifications and application-wide search.
- Public leadership contact and social-media access from the landing page.
- System administration for role management and protected governance functions.

## Stack

Next.js 15, TypeScript, Tailwind CSS, Supabase PostgreSQL/Auth/Storage, Resend, and Gemini.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment

Configure the required Supabase, Gemini, Resend, and role-passcode environment variables in `.env.local` for local development. Production variables are configured separately in Vercel.
